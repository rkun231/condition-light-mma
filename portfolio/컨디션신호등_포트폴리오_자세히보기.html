    본인

  1. 직접 써 보기아이폰 12 Pro에 홈 화면 앱으로 깔아 매일 써 보며 문제를 적었습니다. 한글 입력이 풀리는 문제, 날짜가 멋대로 골라지는 문제가 여기서 나왔습니다.
  2. 자동 테스트컴퓨터에서 아이폰 12 Pro 화면 크기를 흉내 내 처음 설정 → 체크인 → 신호 → 식단 → 내보내기·가져오기를 돌리고, 오류와 가로 넘침을 확인했습니다.
  3. 세 역할 점검고치는 AI, 문제를 찾는 AI, 점수를 매기는 AI를 나눠 제 체크리스트로 점검했습니다. 78 → 84 → 90점.

    설문 · 무엇을 물었고 무엇이 나왔나

    구글 폼으로 만들고 11월 4~5일 인스타 DM으로 MMA 코치·관장, 선수, 기자에게 직접 부탁했습니다. 기자에게는 답 대신 주변 선수·코치에게 전해 달라고 했습니다. 익명이고, 로그인 없이 답할 수 있게 했습니다. 11월 12일 마감입니다.

    질문 (요약)
    1. 어떤 입장에서 답하시나요? 코치·관장 / 프로 / 세미프로 / 아마추어 / 코치이면서 현역
    2. 코치: 지도 경력, 맡는 선수 수, 감량 계획은 누가, 감량·회복을 어디서 배웠나, 의학적 근거가 있나, 어떻게 기록하나, 써 본 앱, 가장 걱정되는 점
    3. 선수: 시합 수, 감량 폭, 물로 빼는 양, 어디서 배웠나, 의학적 근거, 계체 후 물·음식, 겪은 일, 기록 방법, 써 본 앱
    4. 모두: 근거 기반 앱을 쓸 생각(1~5), 필요한 기능, 안 쓸 이유, 불편한 점·자동화하고 싶은 일, 인스타 아이디(동의한 분만)
    응답 3명에서 본 것
    • 겪은 일: 심한 어지럼 2, 경기력 저하 2, 잠들기 어려움 2, 쥐·경련 1, 계체 실패 1
    • 물로 빼는 양: 3~5kg 2명, 1~3kg 1명
    • 계체 후: 3명 모두 전해질 음료 먼저, 그다음 탄수화물
    • 격투기 관련 앱을 써 본 사람 0명 ("아는 앱이 없어서")
    • 근거 기반 앱을 쓸 생각: 5, 5, 3점
    • 필요한 기능: 감량 계획 3, 식단 기록 3, 훈련 강도·회복 계획·코치 공유 각 2

    3명은 경향이 아닙니다. 마감 뒤 다시 정리합니다.

    저장 방식 · 기록은 어디에 있나

    공개 저장소 (코드)
    앱 코드와 음식 영양 DB만 있습니다. 사용자의 기록은 없습니다.
    사용자의 폰
    기록은 폰 브라우저의 localStorage에만 저장합니다. 여러 종목 앱은 condition-note-v1, MMA 앱은 condition-mma-v1로 이름을 나눠, 같은 폰에 둘 다 깔아도 섞이지 않습니다.
    서버
    없습니다. GitHub Pages에 올린 웹페이지 하나이고 기록을 어디로도 보내지 않습니다.
    백업
    설정에서 JSON 파일로 내보내고 가져옵니다. 14일이 지나면 백업하라는 안내가 뜹니다. 엑셀용 CSV도 내보낼 수 있습니다.
    한계
    폰을 바꾸거나 브라우저 기록을 지우면 기록도 지워집니다. 그래서 백업 안내를 넣었습니다. 아이폰은 사파리와 홈 화면 앱의 저장 공간이 따로라서 홈 화면 앱으로만 쓰도록 설명서에 적었습니다.
    체험 휴대폰
    발표 자료의 휴대폰은 실제 앱 파일을 그대로 띄우되, 저장 이름만 condition-portfolio-demo로 바꿔 예시 기록을 넣었습니다.

    나올 만한 질문과 제 답

    의학적으로 안전한가요?
    진단하지 않습니다. 신호는 '오늘 강도를 어떻게 할지' 참고로만 보여 주고, 기준 숫자는 논문과 공식 입장문에서 가져와 출처를 화면에 적었습니다. 다만 의료진의 검토는 아직 받지 못했습니다. 그래서 감량 '계획'처럼 위험할 수 있는 기능은 만들지 않았고, 전문가와 함께 기준을 정한 뒤에 만들 생각입니다.
    실제로 쓰는 사람이 있나요?
    매일 쓰는 사람은 아직 저 하나입니다. 그래서 MMA 코치·선수에게 설문으로 지금 어떻게 하는지부터 물었습니다. 인스타 아이디를 남겨 주신 2명께 MMA 앱을 고친 뒤 사용 후기를 부탁할 계획입니다.
    왜 여러 종목에서 MMA로 좁혔나요?
    설문을 보낸 곳과 응답한 분이 MMA였고, 감량 위험이 가장 크며 계체 회복은 근거가 분명했습니다. 응답 중 "선수 입장에선 모든 걸 다 챙기기 힘들었다"는 말도 있었습니다. 여러 종목 앱은 지우지 않고 그대로 두었고, MMA를 완성한 뒤 합칠 생각입니다.
    AI가 다 만든 것 아닌가요?
    코드는 Claude가 썼습니다. 어떤 기능을 넣고 뺄지, 어떤 기준으로 점검할지, 누구에게 물어볼지는 제가 정했습니다. 아이폰으로 써 보며 문제를 찾고, 코치·선수에게 직접 연락했습니다. AI 의견을 받아들인 것과 바꾼 것은 위의 역할 표에 그대로 적었습니다.
    훈련량 급증 비율은 비판받는 지표 아닌가요?
    맞습니다. Gabbett(2016)의 비율은 Impellizzeri 등(2020)의 비판이 있어서, 앱에서는 '참고 지표'라고 적고 기록이 21일 이상 쌓였을 때만 계산합니다.
    설문 3명으로 무엇을 알 수 있나요?
    경향은 말할 수 없습니다. 다만 제가 생각하지 못했던 것('잠들기 어려움'을 2명이 고름)과, 격투기 관련 앱을 써 본 사람이 없다는 것을 확인했습니다. 11월 12일 마감 뒤 다시 정리합니다.
    비슷한 앱과 무엇이 다른가요?
    컨디션 기록, 증상, 영상, 감량 회복을 한곳에서 다루는 앱은 찾지 못했습니다. 감량은 Fighter Cut이 가장 가까웠고, 공식과 출처를 공개하는 점을 기준으로 삼았습니다. 이 앱은 매일 신호의 이유를 줄마다 보여 주고, 한국어와 한국 음식 DB를 쓰며, 무료입니다.
    기록은 안전한가요?
    서버가 없어서 기록이 폰 밖으로 나가지 않습니다. 대신 폰을 바꾸면 사라질 수 있어 백업 파일로 옮기게 했습니다.
